# models/

Drop your `.gguf` files here. The API host scans this folder on every
`/api/models` request.

Recommended starters:
- Qwen2.5-0.5B-Instruct Q4_K_M   (~350 MB)  smallest, boots instantly
- Qwen2.5-1.5B-Instruct Q4_K_M   (~1 GB)    good balance
- Llama-3.2-3B-Instruct Q4_K_M   (~2 GB)    capable on modest clusters

Sources: https://huggingface.co/models\?search\=gguf
