How it works

Three pieces, one goal: turn idle consumer hardware into a real inference cluster.

◈

Host runs the model

One machine holds the .gguf files and runs llama-server. It scans the models folder, serves the API, and coordinates the cluster — all from a single Python process.

◇

Workers lend their RAM

Any other machine — a laptop, a phone, an old desktop — runs a lightweight RPC server. It receives its share of the model's tensors over the network and computes its slice of every forward pass.

◆

One URL to use it

The chat and dashboard are served by the same process as the API. Open localhost:8000, type, and it just works — no CORS, no Node, no extra config.
